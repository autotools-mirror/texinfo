# The first column holds type names, second column contains flags, third
# column holds associated command id.
#
# Flags for element categories.  Only text used in code
# text: text element
# command: element associated to an @-command.  Instead of testing this type
#          it is in general better to test if cmd is != 0/CM_NONE
# container: other element

# Flags for text elements:
#  leading_space: text elements with spaces appearing before actual text.
#                 To keep in sync with Perl parser %leading_space_types.
#  trailing_spaces: text elements with spaces appearing after actual text.
#                   To keep in sync with Perl parser %trailing_space_types
#  ignorable_text: used in reader to determine the token category.
